# LAP Cerebro

El cerebro del estudio LAP: proyectos de Arquitectura, Diseño Interior, Visualización y Administración, planes de entregables que el equipo aprueba y pasan solos al cronograma de cada persona, reuniones con cliente, comités internos, licencias, planos, obra, horas, finanzas, solicitudes entre áreas y revisión de imágenes, sincronizado en vivo.

- [`app/`](app/LEEME.md): app de escritorio para Windows (Electron).
- [`servidor/`](servidor/LEEME.md): servidor gratuito de la oficina (PocketBase), en un PC o en el NAS.

Los instaladores se generan solos en GitHub Actions y se publican en *Releases* al subir un tag `v*`.
